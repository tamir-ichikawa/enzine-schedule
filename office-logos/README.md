# 事業所別ログインロゴ

ログインURLの `office` と同じ事業所IDをファイル名にしたPNG画像を、このフォルダへ置きます。

例:

```text
office-logos/demo-office-a.png
http://127.0.0.1:5000/?firebaseEmulators=1&office=demo-office-a
```

- ファイル名は `offices/{officeId}` の固定IDを使い、変更可能な事業所名や連番との対応表は作りません。
- 使用できる文字は半角英数字、ハイフン、アンダースコアです。
- PNG画像がない、または読み込めない場合、ログイン画面のロゴ欄は自動的に非表示になります。
- URLの事業所IDはロゴ表示だけに使います。認証後の所属と権限は `users/{uid}` のデータで決まり、URLでは変更できません。
- 画像を追加・差し替えた場合は、通常のサイト更新時にこのフォルダも一緒に配信します。
